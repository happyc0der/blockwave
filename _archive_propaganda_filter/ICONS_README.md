# Icon Files Required

This extension requires three icon PNG files for the Chrome extension interface:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management page)
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## Quick Solution

You can create simple placeholder icons using any of these methods:

### Option 1: Online Icon Generator
1. Visit https://www.favicon-generator.org/ or similar
2. Upload any image or use a text-based icon
3. Download the generated icons and rename them appropriately

### Option 2: Create Simple PNG Files
1. Use any image editor (Photoshop, GIMP, Paint, etc.)
2. Create a 16x16, 48x48, and 128x128 pixel image
3. Save as PNG format with the correct names

### Option 3: Use Default Chrome Icons
You can temporarily use simple colored squares or download free icons from:
- https://icons8.com/
- https://www.flaticon.com/
- https://www.iconfinder.com/

## Icon Suggestions

The extension name is "Propaganda Filter for X", so icons could include:
- A filter/funnel icon
- A shield/protection icon
- An eye with a slash (filtering/viewing control)
- Any simple, recognizable symbol

## Note

The extension will work without icons, but Chrome will show warnings. It's recommended to add at least placeholder icons before using the extension.
